### 5.2 如果需要 playerContent

理解 GM.java 的播放流程：

```
detailContent 返回 vod_play_data
  → GM.java 将其 base64 编码存入 vod_play_url
  → 用户点击播放 → GM.java 解码 base64
  → 用 ext.replace 中的变量按模板拼接 playerContent.loadUrl
  → 加载新 WebView → 脚本 playerContent() 运行
  → 返回 {type: "finalUrl"/"match"} → GM.java 处理
```

必须在 **playerContent 加载的页面** 上测试视频地址提取。

## 编码规范与优化

调试 AVPorner 过程中总结的规范，适用于所有脚本。

### 数据获取

1. **拉取 HTML 源码分析，不要凭经验**。用 `document.documentElement.outerHTML` 保存完整页面，grep 找真实 DOM 结构。选择器必须从 HTML 中确认，不能猜。

2. **jQuery 版本必须匹配页面**。`jQuery.fn.jquery` 看实际版本号，`@require` 用同版本。不一致会导致 `$` 冲突、脚本静默失败。

3. **选择器通过参数传入，不写死在函数内**。`listVideos($cards, titleSelector)` 比 `listVideos()` 内部 hardcode `.video-list-title h4` 更灵活——不同页面传不同选择器。

4. **优先用语义属性**。`[itemtype="https://schema.org/Person"]` 比 `:contains("Pornstars")` 更可靠，不依赖语言和文本变化。

### 选择器设计

5. **用最稳定的容器做卡片循环**。用 `.video-list`（同时包含图片区和标题区）而非 `.video-list-image`（只有图片），避免跨 sibling 查找标题。

6. **不需要过度兼容**。如果 `.duration` 就能取到时长，就不要加 `\d{2,3}:\d{2}` 正则兜底。多余的 fallback 只是噪音。

7. **不需要去重**，除非页面确实有重复卡片。直接 push，让数据完整。

### 函数设计

8. **调用方传 jQuery 对象而非选择器字符串**。`listVideos(jQuery('.video-list'), '.video-list-title h4')` 比 `listVideos('.video-list', '.video-list-title h4')` 更明确——筛选逻辑在调用方，函数只负责遍历提取。

9. **不设默认参数值**。`function listVideos($cards, titleSelector)`，调用方必须显式传参，避免静默用错选择器。

10. **分支用 switch 替代 if/else 链**。多个 `tid` 判断用 `switch (tid) { case 'xxx': ... default: ... }`，结构清晰。

11. **提取循环用 `.each()` 统一**。不管是演员、标签还是片商，都用 `.each()` 遍历提取，格式一致。

### Vod 字段使用

12. **不同字段在不同页面有不同含义**：
    - 列表页 `vod_remarks` → 时长（"153:29"）
    - 详情页 `vod_remarks` → 可点击标签（`[a=cr:...]`）
    - `vod_actor` → 演员（`[a=cr]` 格式，支持点击跳转）
    - `type_name` → 片商/分类名（支持 `[a=cr]` 格式但遥控器无法选中）

13. **`[a=cr:]` 格式要点**：id 使用 `pathname.replace(/^\//, '')` 去掉开头 `/`，与 categoryContent 的 `vod_id` 格式一致。

14. **try/catch 只包可能抛错的最小范围**。`JSON.parse` 需要 try/catch，但元素不存在检查用 `if ($el.length)` 就够了，不需要包在 try 里。

## 参考：完整验证脚本模板

将此模板粘贴到目标页面 Console，一次性输出所有诊断信息：

```javascript
(function fullDiagnostics() {
    const r = {};

    // === 基础 ===
    r.jQuery = typeof jQuery !== 'undefined' ? jQuery.fn.jquery : 'NONE';
    r.pageTitle = document.title;
    r.pageURL = location.href;

    // === CF ===
    r.cf = {
        cfWrapper: !!document.querySelector('#cf-wrapper'),
        loadingVerifying: !!document.querySelector('.loading-verifying'),
        turnstile: document.querySelectorAll('script[src*="challenges.cloudflare.com"]').length,
    };

    // === 内容元素 ===
    r.hasNavigator = !!document.querySelector('.navigator, nav, header nav');
    r.hasContent = !!document.querySelector('.movie, .post, .video-item, article, [class*="movie"], [class*="video"]');

    // === 视频卡片（选一个匹配的） ===
    const cards = document.querySelectorAll('.movie, .post, .video-item, article');
    r.cardCount = cards.length;
    r.sampleCards = Array.from(cards).slice(0, 3).map(el => {
        const a = el.querySelector('a[href]');
        const img = el.querySelector('img');
        return {
            linkHref: a?.href?.slice(0, 80),
            imgSrc: img?.getAttribute('data-original') || img?.getAttribute('data-src') || img?.src || 'NONE',
            imgAlt: img?.alt?.slice(0, 60) || 'NONE',
        };
    });

    // === 分页 ===
    const pager = document.querySelector('.pager, .pagination, [class*="page"]');
    r.pagination = pager ? {
        tagName: pager.tagName,
        html: pager.outerHTML.slice(0, 300),
        text: pager.textContent.trim().slice(0, 100),
    } : 'NOT FOUND';

    // === 视频播放相关 ===
    r.videoFrame = document.querySelector('iframe[id*="video"], iframe[class*="video"]')?.src?.slice(0, 100);
    r.videoTag = document.querySelector('video')?.src?.slice(0, 100);
    r.btnServers = Array.from(document.querySelectorAll('.btn-server, [data-link]')).map(el => ({
        text: el.textContent.trim(),
        dataLink: el.dataset.link?.slice(0, 40),
    }));

    // === 元数据 ===
    r.metaInfo = document.querySelector('.m_information, .info, [class*="meta"], [class*="info"]')?.textContent?.trim()?.slice(0, 200);

    console.log(JSON.stringify(r, null, 2));
    return r;
})();
```

**使用方式**：打开目标网站的首页、分类页、详情页、搜索页各执行一次，对比输出，确认每个页面的选择器一致。
