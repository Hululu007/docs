# 爬虫的常规配置说明

#### 字段说明

| 字段                    | 类型            | 描述                                                         | 备注                                                         |
| :---------------------- | :-------------- | :----------------------------------------------------------- | ------------------------------------------------------------ |
| »`spider`               | `string`        | jar包的网络地址                                              | 本地/自建示例：`./Spiders-Lib/GM.jar;md5;<md5>`；也可使用仓库发布地址（发布后需同步 md5） |
| »`sites`                | `array[object]` | 站点配置                                                     |                                                              |
| »»`key`                 | `string`        | 站点key                                                      |                                                              |
| »»`name`                | `string`        | 站点名称                                                     |                                                              |
| »»`type`                | `int`           | 站点类型，本爬虫类型为`3`（自定义 Jar 爬虫）                 |                                                              |
| »»`searchable`          | `int`           | 是否支持搜索，`0`为不支持、`1`为支持                         |                                                              |
| »»`changeable`          | `int`           | 是否支持换源，`0`为不支持、`1`为支持                         |                                                              |
| »»`api`                 | `string`        | 爬虫类名，本爬虫固定为 `csp_GM`                              |                                                              |
| »»`style`               | `array[object]` | 默认全局样式                                                 |                                                              |
| »»»`type`               | `string`        | 样式类型，可选值 `rect`、`oval`、`list`                      |                                                              |
| »»»`ratio`              | `float`         | 宽高比                                                       |                                                              |
| »»`ext`                 | `object`        | 关于特定爬虫的配置，由爬虫自定义                             |                                                              |
| »»»`userScript`         | `string`        | Userscript 的网络地址                                        | 也支持本地相对路径（相对 index.json）                        |
| »»»`remoteDebug`        | `boolen`        | 是否开启远程调试，默认值由构建注入（本地 `genGM.bat` 为 `true`，CI 为 `false`） | 开启后调用 `WebView.setWebContentsDebuggingEnabled(true)` 并延迟销毁 WebView，可在 Chrome `chrome://inspect/#devices` 调试；**不会让 WebView 变为可见** |
| »»»`logLevel`           | `string`        | 日志级别：`debug` / `info` / `warn` / `error`，默认由构建注入 | 需要查看 `BLOCK:` / `ALLOW:` / `MATCH:` 等过滤日志时必须设为 `debug` |
| »»»`cfAutoHandle`       | `boolen`        | Cloudflare Challenge 自动处理，默认为 `true`                 | 检测到挑战会展示 WebView 供用户验证，脚本无需自己弹窗        |
| »»»`cfVirtualMouse`     | `boolen`        | 挑战期间启用方向键虚拟光标，默认为 `true`                    | 仅 `cfAutoHandle` 生效且确认挑战时出现；方向键移动、OK 点击  |
| »»»`cfRetryOn403`       | `boolen`        | 挑战中的主框架 403 是否补一次同 URL 导航，默认为 `false`     | 会销毁当前挑战文档并换一轮验证，通常应保持关闭               |
| »»»`webViewSettings`    | `object`        | `WebView`的一些具体设置                                      |                                                              |
| »»»»`blockNetworkImage` | `boolen`        | 是否禁止加载网络图片，默认为 `true`                          | 挑战期间会自动临时允许图片；设 `false` 可加载图片（封面等视觉内容） |
| »»»»`blockCssAndFont`   | `boolen`        | 是否屏蔽 CSS 和字体文件，默认为 `true`                       | 挑战期间（含疑似挑战）自动放行，保证验证页正常渲染           |
| »»»»`webViewTimeout`    | `int`           | WebView 加载/等待超时（毫秒），默认为 `60000`                | 挑战期间 `waitReady` 不计入该超时，硬上限约 5 分钟           |
| »»»»`userAgentString`   | `string`        | 自定义 User-Agent 字符串                                     | 用于伪装浏览器标识，不设置则使用系统默认 WebView UA              |
| »»»»`blockList`         | `array`         | 禁止`WebView`加载的内容地址列表（通配符）                    | 匹配 → 拦截。可屏蔽广告/统计/字体/样式；CSS 与字体建议直接交给 `blockCssAndFont` |
| »»»»`allowList`         | `array`         | 白名单（通配符），匹配 → 放行，优先级高于 `blockList`        | 跨域嵌入页/播放页的域名必须写进来；黑白名单均未配置时自动生成「loadUrl 同域 + Cloudflare 域名」的白名单 |
| »»»`playUrlMatch`       | `array`         | 播放链接嗅探规则列表                                         | 自动捕获匹配规则的播放链接（如 `*.m3u8*`），脚本返回 `type: "match"` 时生效 |
| »»»`subtitle`           | `boolen`        | 字幕功能总开关，默认为 `false`                               | 播放时按 `vod_name` 搜索字幕并附加到 `subs`                  |
| »»»`subtitleSettings`   | `object`        | 字幕源配置                                                   | `source` / `languages` / `maxResults` / `cacheTtlMinutes` / `match` |
| »»»`spider`             | `object`        | 关于爬虫各方法的配置                                         | 仅 `homeContent` / `categoryContent` / `detailContent` / `searchContent` 四项生效 |
| »»»»`homeContent`       | `object`        | 主页及分类信息                                               |                                                              |
| »»»»»`loadUrl`          | `string`        | 用于拼装网络地址的模版信息                                   | 使用[StringSubstitutor](https://commons.apache.org/proper/commons-text/apidocs/org/apache/commons/text/StringSubstitutor.html)进行模版替换，支持变量替换和默认值；`homeContent` 无模板变量 |
| »»»»`categoryContent`   | `object`        | 分类下的视频列表                                             |                                                              |
| »»»»»`loadUrl`          | `string`        | 用于拼装网络地址的模版信息                                   | 可用变量：`tid`、`pg`，以及 `extend` 中的筛选项键（如 `sort`、`type`、`tag`、`actress`） |
| »»»»`detailContent`     | `object`        | 视频详情页                                                   |                                                              |
| »»»»»`loadUrl`          | `string`        | 用于拼装网络地址的模版信息                                   | 可用变量：`id`（取 `ids` 的第一项）                          |
| »»»»`searchContent`     | `object`        | 搜索                                                         |                                                              |
| »»»»»`loadUrl`          | `string`        | 用于拼装网络地址的模版信息                                   | 可用变量：`key`、`pg`                                        |

> **播放页地址不来自 `spider` 配置。** `playerContent` 需要加载的页面由 `detailContent` 返回的 `vod_play_data[].media[].ext.url` 决定（`type` 不是 `direct` 时加载该页面）。配置里写 `spider.playerContent.loadUrl` 不会生效。

#### 完整示例

```json
{
  "spider": "./Spiders-Lib/GM.jar;md5;<md5>",
  "sites": [
    {
      "key": "template",
      "name": "模版",
      "type": 3,
      "searchable": 1,
      "changeable": 0,
      "style": {
        "type": "rect",
        "ratio": 0.75
      },
      "api": "csp_GM",
      "ext": {
        "userScript": "./userScripts/template.user.js",
        "remoteDebug": false,
        "logLevel": "info",
        "cfAutoHandle": true,
        "cfVirtualMouse": true,
        "webViewSettings": {
          "blockNetworkImage": true,
          "blockCssAndFont": true,
          "webViewTimeout": 60000,
          "blockList": [
            "https://*.adsco.re/*"
          ],
          "allowList": [
            "https://www.template.com/*"
          ]
        },
        "playUrlMatch": ["https://*/*.m3u8*"],
        "spider": {
          "homeContent": {
            "loadUrl": "https://www.template.com/"
          },
          "categoryContent": {
            "loadUrl": "https://www.template.com/${tid}?page=${pg:-1}&sort=${sort:-}"
          },
          "detailContent": {
            "loadUrl": "https://www.template.com/${id}"
          },
          "searchContent": {
            "loadUrl": "https://www.template.com/search?key=${key}&page=${pg:-1}"
          }
        }
      }
    }
  ]
}
```
