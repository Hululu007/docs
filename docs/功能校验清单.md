# 用户脚本功能校验清单

每个新增脚本必须在浏览器 Console 中逐项验证，全部 ✅ 通过后再提交。

## 校验流程

按顺序逐页执行，每个选择器都必须在对应页面的 Console 中跑通。

---

## 1. 首页 — homeContent

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 1.1 | jQuery 可用 | `typeof jQuery !== 'undefined'` |
| 1.2 | CF 检测 | 检查 `#cf-wrapper`、`.loading-verifying`、`challenges.cloudflare.com` |
| 1.3 | 卡片选择器有效 | 执行 listVideos，`count > 0` |
| 1.4 | 卡片无重复 | `items.length === new Set(items.map(i=>i.vod_id)).size` |
| 1.5 | vod_name 非空 | `sample[0].vod_name.length > 0` |
| 1.6 | vod_pic 非空 | `sample[0].vod_pic` 是有效图片 URL |
| 1.7 | vod_remarks 正确 | 时长/备注格式正确 |
| 1.8 | 分类 class 列表非空 | `classes.length > 0`，每个 `type_id` 能拼出有效 URL |
| 1.9 | 首页能正常加载 | 浏览器直接打开 `loadUrl`，页面标题是站点名 |

## 2. 分类页 — categoryContent

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 2.1 | 分类页能加载 | 用实际 `type_id` 拼出 URL，浏览器能打开 |
| 2.2 | 卡片选择器在分类页有效 | listVideos 返回 `count > 0` |
| 2.3 | 分页有效 | `getPageCount() > 1`（如果有翻页的话） |
| 2.4 | 第 2 页能加载 | 手动打开 `page=2` URL，确认内容和第 1 页不同 |
| 2.5 | 筛选器定义正确 | `filters` 格式为 `type_id: [{key,name,value:[{n,v}]}]` |

## 4. 播放 — play URL

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 4.1 | 播放地址获取成功 | mp4/m3u8/iframe src 提取到有效 URL |
| 4.2 | 直链可访问 | `curl -sI {url}` 返回 200 或 302（非 400/403） |
| 4.3 | 直链需 Referer | `curl -sI` 若无 Referer 返回 403，则需补 header |
| 4.4 | 播放页地址 | 非 `direct` 的 `media[]` 条目，其 `ext.url` 指向的页面能正常加载（播放页地址不来自 `spider.playerContent.loadUrl`） |
| 4.5 | playUrlMatch 精确 | `ext.playUrlMatch` 中每个规则尽量含具体域名，不用 `*` 通配所有域名 |
| 4.6 | 播放链路闭环 | 模拟完整流程：detail 返回 `vod_play_data` → 加载 `media[].ext.url` → 脚本返回 `direct` 或 `match` → 拿到可播放 URL |

## 8. 黑白名单

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 8.1 | blockList 不误伤 | 设 `"logLevel": "debug"` 后查看 `adb logcat -s GMSpider` 中的 `BLOCK:`，确认 jQuery / 视频 CDN / API 未被屏蔽 |
| 8.2 | 广告域名全覆盖 | 对照 Network 面板，常见广告域（magsrv/mnaspm/trackwilltrk 等）均已加入 |
| 8.3 | CSS/字体已屏蔽 | `blockCssAndFont: true`（默认即开）；不要再把 `*.css*`、`*.woff2*` 写进 blockList |
| 8.4 | 播放域名未屏蔽 | 如用 playUrlMatch，视频 CDN 域名不在 blockList 中；跨域嵌入页域名要进 allowList |
| 8.5 | blockNetworkImage | 默认 `true`（可不配）；不影响封面 URL 提取（`src` 属性仍可读） |

## 9. 边缘情况

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 9.1 | 首页加载正常 | `loadUrl` 在浏览器直接打开能加载 |
| 9.2 | vod_id URL 拼接 | 包含 `/` 的特殊格式（如 `html/20898`）在 loadUrl 模板中正确拼接 |
| 9.3 | CF 应对 | `cfAutoHandle` 默认 `true`，挑战时自动弹出 WebView；脚本无需检测/弹窗，且不要在挑战文档里执行 `evaluateJavascript` |
| 9.4 | 空结果不崩溃 | 搜索无结果或分类页无数据时，返回空列表而非报错 |
| 9.5 | 执行时机正确 | 用 `@run-at` 明确指定；省略时按 `document-idle`（包在 `window load` 里）注入，重 JS 页面可能迟迟不触发 |

## 14. 脚本执行时机

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 14.1 | 注入确认 | 在脚本第一行加 `console.log('[XXX] injected, readyState=' + document.readyState)`，确认脚本被执行 |
| 14.2 | 页面加载方式 | 检查 Network 中是否有 `rocket-loader.min.js`（Cloudflare Rocket Loader）或大量延迟脚本，这类页面 `window load` 可能不触发 |
| 14.3 | 显式指定 `@run-at` | 支持 `document-start` / `document-end` / `document-idle`（默认）；三者都在 `onPageStarted` 注入，`end` 包 `DOMContentLoaded`、`idle` 包 `window load`。对 Rocket Loader / 重 JS 页面用 `document-end` 或 `document-start` |
| 14.4 | 卡片存在检测 | 注入后检查目标元素是否存在（如 `.video-list-image`），不存在时轮询/`setTimeout` 等待，不要写死长延时；WebView 整体超时由 `webViewSettings.webViewTimeout` 控制（默认 `60000` 毫秒） |
| 14.5 | 防重复执行 | 如果你的脚本自己同时监听 `DOMContentLoaded` 和 `load`，用标志位防止重复执行；用 `@run-at` 时框架只注入一次 |

## 快速验证模板

将此脚本粘贴到目标页面 Console，一键输出校验结果：

```javascript
(function verify() {
  const r = {};
  r.jq = typeof jQuery !== 'undefined';
  r.cf = !!document.querySelector('#cf-wrapper,.loading-verifying');
  r.page = location.href;

  // 列表
  r.hasCards = jQuery('.video-item,.video-list-image,.movie,.post,.item,article,[class*="card"]').length > 0;
  r.videoLinks = jQuery('a[href*="/video/"],a[href*="/watch/"],a[href*="/jav/"],a[href*="/html/"]').length;

  // 详情
  r.hasH1 = jQuery('h1').length > 0;
  r.hasOgImage = jQuery('meta[property="og:image"]').length > 0;
  r.hasVideoSrc = jQuery('video source').length > 0;
  r.hasVideoTag = jQuery('video[src]').length > 0;
  r.hasIframe = jQuery('iframe[src*="video"],iframe[src*="embed"],iframe[src*="player"]').length > 0;

  // 演员/标签
  r.actorLinks = jQuery('a[href*="/models/"],a[href*="/star/"],a[href*="/actress/"],a[href*="/cast/"],a[href*="/pornstars/"]').length;
  r.tagLinks = jQuery('a[href*="/tags/"],a[href*="/categories/"],a[href*="/type/"],a[href*="/genre/"]').length;

  // 分页
  let mp = 1;
  jQuery('.pagination a,.page-numbers,.pager_button').each(function(){const n=parseInt(this.textContent);if(n>mp)mp=n;});
  r.maxPage = mp;

  // 播放
  r.playUrl = jQuery('video source').attr('src') || jQuery('video[src]').attr('src') || '';

  console.log(JSON.stringify(r, null, 2));
  return r;
})();
```
